═══ 01_DRAFT ═══

OpenAI has launched the Agents API in public beta, making the harness and infrastructure that powers Codex and ChatGPT for Work available to developers through a single API call. The release allows developers to specify tasks, models, tools, and environments to create production-ready agents that can run reliably for days. Developers can choose between an OpenAI-managed sandbox or compute environments provided by ecosystem partners including Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, and Vercel. The API is powered by the open-source Codex harness, which OpenAI hosts and maintains to manage context, tool usage, and subagent coordination. Features of the new API include automatic context compaction for long-running sessions, tool search and programmatic tool calling to reduce token usage and cost, and multi-agent support for breaking tasks into independent, parallel subagent workflows. There are no additional fees for using the Agents API during the public beta, and developers simply pay for the standard tokens and tools their agents consume.
