═══ 01_DRAFT ═══

OpenAI introduced the Agents API in public beta, giving developers access to the same agent harness and infrastructure that powers Codex and ChatGPT for Work. The API allows developers to create a production-ready agent in a single call by specifying the task, model, tools, and environment. OpenAI hosts and maintains the harness while developers choose between an OpenAI-managed sandbox, their own infrastructure, or integrations with ecosystem partners including Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, and Vercel. Features of the Agents API include automatic context compaction for long-running sessions, tool search and programmatic tool calling to reduce token usage and cost, and multi-agent support that delegates tasks to parallel subagents. The API is powered by the open-source Codex harness, which is available for inspection via a public codebase. There are no additional fees for using the Agents API during the public beta; developers simply pay for the tokens and tools their agents use.
