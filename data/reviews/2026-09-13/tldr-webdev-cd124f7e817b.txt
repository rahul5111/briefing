═══ 01_DRAFT ═══

Google Chrome has released modern-web-guidance, an npx-based command-line tool that acts as a search index over a curated set of best-practice web development guides. The tool was recently tested as an auditor on a 42-file Vite and React 18 internal questionnaire app. 

The audit surfaced several stale coding patterns. For dark mode, the app relied on hardcoded light theme hex values with no color-scheme declarations. The skill retrieved a dark-mode guide with a similarity score of 0.75, highlighting two mandatory declarations to prevent a flash of un-themed content: a meta tag in the document head and a root style declaration using color-scheme light dark. The guide also recommended the light-dark function for color tokens and noted that color-scheme achieved Baseline Widely Available status on February 3, 2022, while light-dark became newly available on May 13, 2024.

For form handling, the app used bare inputs and buttons without form elements, missing native features like Enter-to-submit. The search surfaced a forms guide advising developers to wrap interactive controls in form elements and use type submit instead of type button for primary submissions. 

For validation, the skill retrieved guides built around the user-valid and user-invalid pseudo-classes, recommending validation on blur and error reset on input. The tool also flagged the use of min-height 100vh in mobile contexts, where dynamic viewport height units are preferred. 

The skill indexes guides using action-oriented search phrases and retrieves full markdown guides, providing developers with actionable platform primitives and explicit browser-support timelines based on Baseline status.
