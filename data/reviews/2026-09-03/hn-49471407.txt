═══ 01_DRAFT ═══

Developers have launched an open-source model gateway designed to manage self-hosted, frontier, and open-source artificial intelligence models from a single interface. Built natively in Rust for concurrency, the gateway standardizes configuration quirks across different models and providers, including streaming formats, tool calls, model parameters, rate limits, and error behaviors. The system adds under one millisecond of latency for bring-your-own-key requests and under two milliseconds when the platform supplies the provider key. It supports every major inference provider and offers over one thousand models refreshed daily through a codex agent that automatically opens pull requests. Unlike other routing services that charge a ten percent token markup, this project takes no markup, operates as open source for deployment on local infrastructure, and features an opt-in program to use user traffic for training custom models. To optimize routing, the gateway uses standardized OpenTelemetry traces to mine representative real tasks, simulates rollouts using text world models, applies an LLM judge, and fits a nearest neighbor classifier over prompt embeddings to determine the optimal model for each request. These simulations also enable suggestions for cache hit optimizations, new model options, and customized model training.
