3. Running on a 48 GB Mac achieves approximately 12 tokens per second warm decode speed.
4. The engine requires Apple Silicon, macOS 14 or later, and approximately 110 GB of free disk space.

═══ 01_DRAFT ═══

A new project called slotstream enables users to run the 125 billion parameter mixture-of-experts model Qwen3.8-Flash-Next on memory-constrained Apple Silicon Macs. The utility is distributed as a single Swift binary without Python dependencies and supports the Ollama and OpenAI chat application programming interfaces.

Running the model requires macOS 14 or later and approximately 110 GB of free disk space, making a 512 GB Mac the realistic minimum. The engine uses MLX and Metal, streaming experts from the SSD straight into unified memory. On a 48 GB MacBook Pro, the system achieves a warm decode speed of roughly 12 tokens per second.

The tool features auto-sizing that limits memory consumption to prevent excessive swapping. It includes features such as speculative decoding via a 1.5 GB draft head that is correct 86 percent of the time, prefix caching for conversation turns, and a context cap of 32,768 tokens. Installation is available via a shell script, and assets can be verified using GitHub attestation.
