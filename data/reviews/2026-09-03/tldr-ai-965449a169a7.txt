═══ 01_DRAFT ═══

Meta is preparing to launch its planned agent super app under the name Muse, aligning the product with the branding used for the company's new generation of artificial intelligence models. The project was previously known internally as Project Hatch. The clearest change has appeared on iOS, where an app used for internal testing has transitioned into a Muse waitlist experience. Joining the waitlist appears technically possible, though Meta has not yet opened it publicly. Meta is also updating its desktop app with theme support, secondary color selection, and a monochrome theme. More significantly, Meta has added a setting for computer use and is testing a model variant called Ava, which is described as supporting computer control, though Ava itself is not currently accessible. These additions indicate that Muse could allow an AI agent to operate desktop applications and browse the web as part of longer, multi-step tasks, placing the product closer to tools like Codex and Claude. This direction mirrors Meta's broader strategy, as Muse Spark 1.1 and 1.2 already emphasize tool use, coding, and computer control. Previous reports regarding Project Hatch indicated the product would be capable of using websites, managing schedules, sending emails, and building custom tools, with Meta reportedly considering premium pricing as high as $200 per month. The transition to a waitlist suggests a controlled rollout where Meta could announce the app first and gradually admit users while computer and browser control features mature.
