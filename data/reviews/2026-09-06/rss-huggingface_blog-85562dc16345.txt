═══ 01_DRAFT ═══

Hugging Face has released an initial collection of 207 optimized WebGPU kernels under the Apache 2.0 license, alongside a JavaScript loader package called @huggingface/kernels and a crowdsourced benchmarking suite named Fleet. 

The collection covers core machine learning operations such as matrix multiplications, normalizations, and attention primitives. Each kernel is published as a complete, versioned package on the Hugging Face Hub, containing a manifest, correctness cases, benchmark data, and parameterized WGSL shader templates. Developers can install the preview package using npm install @huggingface/kernels@preview and execute kernels by passing tensor shapes and data through a unified JavaScript contract.

In performance comparisons against ONNX Runtime Web using version 1.30.0-dev.20260826-b1f76d586a on an Apple M4 GPU across 809 matching test cases, the new kernels achieved a geometric mean speedup of 2.57x and a median speedup of 1.90x, securing 629 wins, 176 losses, and 4 ties. Certain complex operations yielded larger performance gains, including a bilinear Einsum case that ran more than 10,000 times faster and a row-wise CumSum that was 301 times faster. These measurements reflect isolated GPU execution times and exclude setup overhead.

To address hardware variability across devices, browsers, and drivers, the Fleet tool enables users to run browser-based correctness and performance checks. With user consent, these runs privately contribute evidence back to help identify device-specific failures and guide future optimizations. Hugging Face is also collaborating with the ONNX Runtime team to upstream these improvements into the broader ONNX Runtime Web ecosystem.
