═══ 01_DRAFT ═══

OpenAI enterprise data shows top tier firms now generate 8.3 times as many output tokens per active user as typical firms, up from 2.6 times in January, signaling a shift from AI assistance to execution. Startups Basis, Clay, and Exa Labs are implementing this shift by deploying agents into core operations like onboarding, account management, and developer integrations. Basis reduced employee onboarding from two hours to 30 minutes by using Codex to handle integration setups and deliver company-specific skills on day one. Clay deployed dedicated subagents that review primary CRM, Slack, and email sources overnight to update deal folders, saving go-to-market engineers roughly an hour of inbox triage each night. Exa Labs uses Codex to monitor integration opportunities, create pull requests, run tests, and prepare weekly updates while keeping human review points before shipping. Enterprise leaders are advised to target consequential workflows, define clear measurement metrics, write specific agent job descriptions, build supporting human oversight systems, and capture successful experiments as reusable skills to scale operating capability.
