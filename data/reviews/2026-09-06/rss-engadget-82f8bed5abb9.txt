═══ 00_KEY_POINTS ═══

1. Storage drives tend to fail unexpectedly, which can lead to corrupted files, system crashes, or disappearing drives.
2. Users should immediately back up important files if their PC experiences slow access, errors, or unusual drive sounds.
3. Windows 11 settings can display estimated remaining life and temperature for supported NVMe solid-state drives.
4. Windows health monitoring does not cover SATA solid-state drives or traditional mechanical hard drives.
5. Users can check their drive status using PowerShell by opening a terminal tab and typing Get-PhysicalDisk.
6. CrystalDiskInfo is a free third-party tool that reads SMART data and provides health statuses like Good or Bad.
7. If a drive receives a Caution or Bad result, backing up data immediately becomes the absolute priority.

═══ 01_DRAFT ═══

Storage drives can fail unexpectedly, with traditional hard drives sometimes producing clicking or grinding sounds while solid-state drives have no moving parts to warn users. Problems with either type can appear as corrupted files, slow access, read or write errors, crashes, or a drive disappearing from Windows. Users experiencing these issues should back up important files immediately before running diagnostics. Windows 11 offers built-in methods to check drive health, though available information depends on the hardware. Users can open Settings, navigate to System, Storage, Advanced storage settings, Disks and volumes, and select a drive and its properties to view estimated remaining life, available spare capacity, and temperature for supported NVMe solid-state drives. Windows can alert users if spare capacity is low, reliability decreases, or the drive enters read-only mode, though Microsoft states this monitoring does not cover SATA solid-state drives or traditional hard drives. Another quick check involves opening a PowerShell tab in Windows Terminal, typing Get-PhysicalDisk, and checking the HealthStatus column for a result of Healthy, Warning, Unhealthy, or Unknown. Microsoft recommends PowerShell because older commands like wmic have been removed from supported versions of Windows 11. For a second opinion, the free tool CrystalDiskInfo reads SMART data from many drives and assigns a health status of Good, Caution, Bad, or Unknown. Users receiving Caution or Bad results should prioritize backing up data and verify issues using manufacturer diagnostic software such as Seagate SeaTools or Samsung Magician. Persistent warnings, unhealthy results, or mechanical symptoms mean users should stop trusting the drive with unique copies of important data and consider a replacement. Additionally, the CHKDSK utility checks file systems and metadata for errors, with the f option fixing file-system errors and the r option locating bad sectors and attempting to recover readable data. However, correcting file-system problems with CHKDSK does not repair questionable hardware.
