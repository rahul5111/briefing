═══ 01_DRAFT ═══

The Three-LLM library runs large language models locally in the browser by translating their inference graphs into Three.js TSL compute shaders on WebGPU without requiring a server-side inference runtime or model-specific WebAssembly binary. The project supports models ranging from a 3-million parameter story generator to a modern 800-million parameter chat model, specifically recognizing GPT-2, Llama-style, Gemma 3, Phi, and Qwen3.5 architectures. A quick chat application included with the library allows users to try five checkpoints, which are TinyStories GPT-2 3M, GPT-2 124M, SmolLM2 135M, Qwen3.5 0.8B, and Phi-1.5 1.3B. Model files range in size from 15 megabytes to 2.8 gigabytes before Three-LLM expands their weights to 32-bit floats. The library reads standard Hugging Face config.json files, tokenizer files, and SafeTensors weights at runtime, using CPU reference implementations for validation and GPU implementations for actual use.
