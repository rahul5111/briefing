═══ 01_DRAFT ═══

Using Claude Opus within a specialized code-server harness, a researcher took an actively exploited zero-day patch for PaperCut NG and, in roughly 90 minutes across 10 prompts, 293 tool calls, and 224 million tokens, identified three critical vulnerabilities, built a full-chain proof of concept for unauthenticated code execution, and found bypasses for the released patches. 

Operating on August 27, 2026, the AI agent began by extracting installers with the -e flag for patch diffing and deploying an Ubuntu 24.04 cloud template on Proxmox to replicate the issue. By 23:05, the model located the root cause in the ExternalUserLookupDb class, noting that version 26.0.4 blocked SQL template injection strings such as CALL, EXEC, EXECUTE, and SYSCS_* against PaperCut's bundled Apache Derby database.

After encountering an authentication filter mismatch in WebConfig, Claude tested various routes before confirming an active bypass at 23:18. Specifically, the path `/api/web;x/footer` returned an unauthenticated HTTP 200, whereas `/api/web/footer` returned 401, demonstrating that a matrix parameter on an earlier segment defeats the filter's `.contains()` check while Spring strips it to route to the controller.

When an initial attempt to chain the SQL component failed because the bypass did not reach the required endpoints, the human operator challenged the AI's reliance on localhost credentials. At 23:57, just under an hour into the session, Claude identified the missing link in BasePaperCutPage.pageValidate. The patch showed that version 26.0.3 checked access rights only for the single page Tapestry resolved while permitting the service request parameter to name a different, privileged page.

═══ 04_AUDIO_REWRITE ═══

Ten prompts. Two hundred ninety-three tool calls. Two hundred twenty-four million tokens. Ninety minutes. One guardrail. Claude Opus took a patch for a zero-day. It identified three critical vulnerabilities. It created a full chain proof of concept. This resulted in unauthenticated code execution on a Papercut N. G. software stack. Then it found a bypass for the patches that had already been released. 

The researcher was in the United Kingdom around eleven p.m. catching up on news feeds. An actively exploited vulnerability had been public for a few hours. Patches were out but no public proof of concepts existed yet. This was a perfect opportunity to test the model on N-day capabilities. 

The harness was deployed in a code-server instance for isolation. The agents had full root permissions to install any additional tools they needed. The setup started with Opus five using a one million context and extra high effort. The first step was identifying the patch and the vulnerable version. A vulnerable version was deployed to the Proxmox range. Then patch diffing began based on reports and indicators of compromise.

Agents researched the vulnerability by pulling advisory details and checking the Proxmox node. Within two minutes they identified the root cause analysis, found the patches, and started building a test instance. While one agent stood up infrastructure, another agent started patch diffing and decompiling. By twenty-three o five, Claude found the root cause. 

Over the next fifteen minutes, the model figured out exposure. It identified a likely S. Q. L. issue and how an attacker could reach it. The agents spent a few minutes decompiling Java bytecode and diffing files to trace code paths, sinks, and sources. At twenty-three twelve, an agent found a way to bypass authentication and checked the virtual instance to validate the findings. 

The agent tested path manipulation against the instance and read server logs. It noticed the server was installed but not configured. It fired up another agent and used the Playwright M. C. P. to drive the installation. A few minutes later the installation succeeded and the agent retested. 

At twenty-three seventeen, the system hit a guardrail. Writing exploits was permitted, but hunting for signs of exploitation triggered the block. The harness transitioned the task over to Opus four point eight and work continued. At twenty-three eighteen, the first auth bypass mechanism was confirmed. At twenty-three twenty-three and thirty-nine seconds, Claude triumphantly declared it had the full exploit chain.
