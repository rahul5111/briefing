═══ 01_DRAFT ═══

A new open-source AI agent called Copperhead has been launched to design, document, and verify printed circuit boards using KiCad files and git repositories. 

The tool runs a pipeline across eight sequential stages, moving from an initial written brief through specifications, architecture, parts selection, schematic design, layout, output generation, firmware, and a development plan. Each stage acts as a gated agent run that must leave verified artifacts on disk before the next can begin, and every hop requires electrical rules checks and design rules checks to be clean in KiCad. 

Copperhead is designed to prevent documentation and design drift, which occurs when a hardware change falls out of sync across a schematic, bill of materials, and power budgets. According to the project details, discovering these inconsistencies late during hardware bring-up typically results in a respin cost of five thousand to fifty thousand dollars and a delay of six to eight weeks. 

The software utilizes an open-core business model. The command-line interface is free to use locally with a user-brought Claude or GPT-5 API key, working on local machines without metering or vendor lock-in. Paid tiers include a cloud option priced at forty-nine dollars per user per month that adds hosted runs, a web viewer, and export tools. A team tier matches the cloud pricing to provide governance features and a continuous integration bot, while a custom enterprise tier offers self-hosted deployments, an audit trail, compliance support, and Altium compatibility.
