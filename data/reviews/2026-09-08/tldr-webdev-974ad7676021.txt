═══ 01_DRAFT ═══

At a QCon London 2026 talk, SpiralDB maintainer Onur presented Vortex, an open-source columnar file format hosted under the Linux Foundation designed to accelerate machine learning data loading from cloud storage like S3 directly to GPUs. 

Traditional ML training pipelines suffer from two major overheads: movement taxes caused by multi-step data transfers through NVMe disks, CPU RAM, and CPU decompression before hitting the PCIe bus, and decision taxes requiring full data reprocessing when altering training filters or data mixes. Vortex eliminates these bottlenecks by utilizing lightweight, cascading encodings that allow GPUs to handle parallel decompression directly, and by pushing projections, filters, and aggregations down into the file format itself so queries can be modified without full data re-tokenization. 

According to the presentation, Vortex S3-to-GPU scans run roughly 30 times faster than Parquet, while its random access speeds are 100 times or more faster than Parquet. The file format relies on decoupled logical and physical types, fixed-size postscripts, a descriptive footer, and a structure of arrays and layouts. Layouts use zone-maps containing summary statistics like minimum and maximum values, allowing readers to prune unnecessary data segments before performing sliceable compression where only matching row ranges are decompressed.
