═══ 01_DRAFT ═══

Attackers compromised Coder’s Cloudflare infrastructure and added unauthorized registry servers that delivered malicious Terraform modules containing credential-stealing code. Coder disclosed that an attacker targeted registry.coder.com on Monday, August 31, accessing its underlying infrastructure to add unauthorized IP addresses to the pool. Cloudflare then routed some registry requests to the attacker's servers instead of legitimate ones. The delivery window for the malicious artifacts lasted from 07:35 UTC to 21:45 UTC on August 31. An unidentified malicious actor gained access to Coder’s Cloudflare infrastructure and added unauthorized IP addresses to the pool used for Coder’s module registry, and these unauthorized IP addresses hosted a version of Coder’s registry that contained artifacts which included malicious code, according to Coder's advisory. The modified Terraform modules acted as information stealers on infected hosts, searching for environment variables, secrets, API keys, CI/CD credentials, terminal history, OIDC tokens, SSH keys, external authentication tokens, and Coder database passwords. Collected information was exfiltrated to the domain coder-infra.com. Coder recommends that potentially impacted users rotate all impacted secrets as soon as possible and examine firewall, proxy, DNS, and VPC flow logs for connections to the malicious domain before upgrading to patched releases 2.37.0, 2.36.4, 2.35.7, and 2.34.9. Developers should also search provisioner logs for data.external.telemetry, identify modules downloaded during the exposure window, and purge potentially malicious cached packages. Coder shared an SQL query to help identify potentially affected cached modules and template versions, noting that refresh tokens were not passed to the provisioner and there was no evidence of impact to customer data maintained by Coder. Because the attacker's infrastructure is outside the project's control, Coder does not have access to crucial logs and cannot conclusively identify every compromised deployment used by prominent organizations including Dropbox, Palantir, Square, Mercedes-Benz, KKR, EnBW, and the U.S. government.
