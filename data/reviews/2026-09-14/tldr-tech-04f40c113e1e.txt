═══ 01_DRAFT ═══

East River Source Control has been operating for over a year and is developing a next-generation version control system designed to address the limitations of Git in the era of agentic development. The company states that the rise of AI agents is producing faster code generation, ballooning repository sizes, and increased merge contention that strains traditional version control systems built around 2005 constraints and open-source models like the Linux kernel. To bridge the gap between current tools and future needs, East River Source Control is building a custom storage engine that allows developers to connect using standard Git clients and protocols without storing actual Git repositories on its servers. The architecture is horizontally scalable and supports independent deployments. Additionally, the system incorporates the Jujutsu version control system, allowing teams to start with regular Git while individual developers can adopt Jujutsu incrementally, with future plans to support alternative protocols using the same underlying engine. Storage is being released as the first foundational building block, designed to integrate with custom software stacks rather than a unified software forge. No products are available yet, but the company plans to share announcements soon and will appear at JJ Con.
