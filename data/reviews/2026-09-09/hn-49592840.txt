═══ 01_DRAFT ═══

A developer has launched GET Together, a new social network that operates entirely through HTTP GET requests instead of POST requests. Hosted at gettogether.dev, the platform allows users to publish public posts by including their nickname and text as query parameters in a URL. The site features a reverse-chronological feed, support for threaded replies, heart reactions, and post deletion, all driven by GET requests. Nicknames must be between two and twenty characters using letters, numbers, or underscores, and do not require verification or uniqueness. Users can optionally store a gt_session cookie to manage post deletion, while duplicate post IDs or identical text submissions return a 409 Conflict error. The platform implements automated moderation checks that screen new posts and names for English profanity as well as cryptocurrency, Bitcoin, memecoin, and token promotion. Because everything is submitted via URL parameters, the platform warns users that post text is public and should not contain private information.
