═══ 01_DRAFT ═══

Hackers have breached F5 BIG-IP APM devices using a Linux rootkit that deploys a fileless memory-resident web shell, according to security researchers from Sophos and ESET, who tracks the malware as PoisonedRefresh. The payload was likely deployed after attackers exploited CVE-2025-53521, a critical remote code execution flaw that F5 Networks reclassified from a denial-of-service problem in March. The malicious installer infected the Apache executable on BIG-IP APM systems, modified SELinux configurations, and maintained persistence across BIG-IP upgrade images. Sophos researchers stated that the second-stage sample hides key operational strings with RC4, gains execution before the host application main function is invoked by intercepting libc start main, targets Apache's PHP module by hooking the Apache Portable Runtime module loader, and injects a PHP web shell into memory. The implant intercepts PHP file operations to hide the web shell inside legitimate scripts like apm css.php3, full wt.php3, and webtop popup css.php3, leaving files on disk unchanged to reduce detection. The injected web shell processes magic requests, executes them via PHP eval, and returns an HTTP 201 response disguised as CSS content. The rootkit also includes a protection mechanism delaying local backdoor creation to prevent service disruption, and creates a password-protected local communication socket that launches an interactive Bash shell without using a TCP listening port. The ShadowServer Foundation reported that 795 vulnerable F5 BIG-IP APM endpoints were exposed online yesterday. Defenders are advised to investigate unusual POST requests to targeted .php3 endpoints and responses combining HTTP 201 with a text/css content type.
