═══ 01_DRAFT ═══

PlanetScale has announced the platform preview release of Neki, a sharded PostgreSQL database designed to help fast-growing applications scale across multiple machines while running real PostgreSQL on every shard. Built using lessons from running large sharded MySQL clusters over eight years, Neki addresses the upper limits that engineering teams face when their PostgreSQL databases outgrow a single machine.

Applications connect to a Neki router using the standard PostgreSQL wire protocol, allowing existing drivers, ORMs, and connection strings to continue working without modification. Each shard consists of a full PostgreSQL cluster with one primary instance and at least two replicas distributed across three availability zones, utilizing no custom storage engines. 

The architecture consists of four main components. Neki routers feature a full PostgreSQL query parser and distributed query planner to send work to appropriate shards and combine results. Shards are organized into shard groups with specific configuration profiles, allowing different tables or workloads to use tailored instance sizes, replica counts, and extensions. Sidecars run alongside every PostgreSQL instance to handle connection pooling directly between the router and database layers. The control plane monitors node health, manages failovers, and coordinates operational workflows.

Users define data placement and routing using a JSON data topology that maps logical tables to physical shards using defined shard indexes and groups. Routine maintenance operations such as schema changes, version upgrades, failovers, imports, and resharding run as built-in online workflows. Neki also includes PlanetScale features including Insights, schema recommendations, branching, and MCP. 

Teams can initially run Neki as a single primary with replicas before resharding the existing cluster when capacity demands it. PlanetScale cautions that users should not run production workloads on Neki during the platform preview due to ongoing changes that may include breaking updates. Interested users can sign in to PlanetScale, opt into the platform preview, and create a cluster, or contact the team for a private demonstration.
