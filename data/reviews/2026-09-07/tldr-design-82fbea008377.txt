═══ 01_DRAFT ═══

Solaris is a new AI system classified as an Interface World Model, built on the Gen-4.5 video generation model and adapting the general world model approach known as GWM-1. Unlike traditional operating systems that rely on fixed code and intermediate representations like HTML or JavaScript, Solaris generates interactive software interfaces frame by frame in real time as the user acts. 

The system handles rendering and interactions jointly, combining a language model that interprets user requests with a world model that streams 720p visuals. To achieve interactive speeds, the developers converted the model to generate frames autoregressively, distilled the denoising process, and trained the engine on its own outputs to maintain session coherence. 

Solaris introduces three primary capabilities: it is entirely visual without a hidden implementation layer, it is continuously alive and evolving, and it is open-ended to support dynamic user actions. In a user study involving 250 participants and 30 interaction examples yielding nearly 7,500 pairwise judgments, participants preferred Solaris over a state-of-the-art language model, Claude Opus 5, in 61 percent of comparisons for following requested instructions, compared to 24 percent for the coded interface approach.
