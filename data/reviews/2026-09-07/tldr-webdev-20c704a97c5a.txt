═══ 01_DRAFT ═══

By 2028, AI coding costs are projected to exceed the average developer salary, with a quarter of engineering leaders already spending two hundred to five hundred dollars per developer monthly on tokens, and some exceeding two thousand dollars. To combat this, a developer reduced Claude Code token usage by ninety percent using AiKA Modes in Portal by Spotify, which delegates heavy input-output tasks to Gemini 2.5 Flash as a worker model.

The setup relies on two public declarative modes running on ephemeral runtimes. The bulk-reader mode analyzes code and outputs structured bullets from large files, while the code-writer mode generates boilerplate code matching existing patterns based on a spec and reference file. A Claude Code plugin called shunt enforces this routing through hooks and bash scripts. PreToolUse hooks intercept read calls on files exceeding a default threshold of three hundred fifty lines, blocking the read and directing Claude to use the bulk-reader skill instead. 

Benchmarks across a Java monorepo showed mean bulk-read token savings of approximately ninety percent. However, the system cannot delegate editing because summaries lack reliable line numbers, nor can it delegate reasoning, debugging, or architectural decisions. Network round-trips add ten to thirty seconds of latency per delegation, making the approach inefficient for small tasks. 

Developers can implement this setup by installing the spotify/portal-ai-plugins marketplace plugins via the Claude CLI, running portal setup to authenticate, and utilizing the pre-configured public modes.
