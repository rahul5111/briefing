═══ 01_DRAFT ═══

Threat actors are exploiting newly disclosed PaperCut vulnerabilities to target the education sector in the United States and Europe for credential theft. According to the Arctic Wolf Adversary Research Team, attackers are chaining CVE-2026-81578, an authentication bypass, and CVE-2026-82078, a remote code execution flaw, to conduct command execution, reconnaissance, and create privileged accounts.

Observed post-exploitation activity includes the delivery of Windows registry hive collection tools, Metasploit and Meterpreter-related Java payloads, and commands used to identify hosts, users, processes, and sensitive configuration data. Malicious actions documented by Arctic Wolf involve running discovery commands like uname, whoami, ver, and tasklist, alongside the creation of a privileged account named Administrator17. Attackers also used certutil.exe to deliver credential-harvesting tools such as lsa_collect.exe, lsa_collect_small.exe, and save_hives.exe from the IP address 45.142.193.132, while retrieving Meterpreter Java payloads from 194.180.48.134. Additional tactics included using findstr to search PaperCut configuration files for terms including password, secret, ldap, bind, and token.

In one sandboxed instance, lsa_collect.exe extracted specific registry keys to reconstruct the system BootKey, granting access to the Security Account Manager database. Arctic Wolf stated that the concern is that those stolen logins could give attackers a pathway into other critical systems across the environment. Users are advised to restrict PaperCut servers from internet exposure and monitor for the execution of command-line tools like cmd.exe and powershell.exe when spawned by pc-app.exe.
