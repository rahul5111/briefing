═══ 01_DRAFT ═══

JetBrains is urging users of its Cadence cloud computing service to immediately revoke and rotate all credentials following a security breach discovered on August 23, 2026. Unidentified threat actors exploited an unpatched, critical vulnerability in TeamCity, tracked as CVE-2026-63077 with a CVSS score of 9.8, to breach the affected environment between August 8 and 24, 2026. The flaw allows unauthenticated attackers to bypass authentication checks and execute arbitrary operating system commands. CISA added the vulnerability to its Known Exploited Vulnerabilities catalog on August 5, 2026, and JetBrains conceded that the compromised server should have been patched during its vulnerability response efforts. The affected server, api.cadence.jetbrains.com, has been taken offline, and JetBrains has invalidated all access tokens used by the PyCharm Cadence plugin. Investigators confirmed the attackers accessed personal data including usernames, real names, email addresses, last-login timestamps, and IP addresses, alongside a full Cadence server backup from 2024. This backup contained configuration data, logs, artifacts, and multiple AWS IAM users and associated credentials, including those belonging to JetBrains employees. Threat actors also accessed files stored in S3 buckets within JetBrains AWS accounts used by Cadence and potentially viewed source code synchronized from PyCharm projects. Daniel Gallo, Solutions Engineering Lead at JetBrains, stated that the findings did not identify any additional affected users beyond the group previously contacted directly, noting that "as a precaution, we are treating the data stored there as potentially exposed." JetBrains warned that the personal data exposure increases the risk of targeted phishing, social engineering, and impersonation, and advised users to treat all Cadence executions, inputs, and outputs as potentially untrusted while auditing connected systems for suspicious activity.
