═══ 01_DRAFT ═══

Online stores running Adobe Commerce and Magento Open Source are facing active attacks from a maximum-severity, zero-day vulnerability tracked as CVE-2026-75650. The flaw carries a CVSS score of 10.0 and impacts versions 2.4.4 through 2.4.9 of both platforms. Security firm Sansec, which dubbed the flaw StyleSmuggler, found that exploitation began on September 4, with the first confirmed attack recorded at 22:20 UTC. 

The unauthenticated vulnerability allows attackers to inject malicious PHP code by abusing template processing during failed payment email notifications. When the attack succeeds, a background process is launched. According to Sansec researchers, when the attack succeeds, a backdoor background process is launched. This is a small Rust program that connects to the 99.84.67.186 C2 server and waits for commands. The Rust implant uses persistence mechanisms such as cron jobs and disguises its command-and-control traffic as NTP traffic over UDP port 123. The investigation also revealed a separate attacker using the vulnerability to deploy a web shell inside the product-image cache on September 7. 

Adobe has released an emergency hotfix, VULN-393411, to close the vulnerability. However, because attackers had a three-day window to exploit the flaw before the fix arrived, Sansec warns that patching alone is insufficient for stores that may have already been compromised. Operators are advised to scan systems for unexpected PHP files, malicious processes, and cron entries, and to rotate potentially compromised credentials and secrets.
